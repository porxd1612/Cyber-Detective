# Cyber-Detective

**Digital Incident Investigation Simulator**

Cyber Detective คือเกมจำลองการสืบสวนเหตุการณ์ด้านความปลอดภัยทางดิจิทัล พัฒนาด้วย Python และ Tkinter ผู้เล่นจะรับบทเป็นนักสืบ วิเคราะห์หลักฐานจากหลายแหล่ง เชื่อมโยงเหตุการณ์ และเลือกข้อสรุปที่มีหลักฐานสนับสนุนมากที่สุด

## Features

- วิเคราะห์หลักฐานจาก Email Gateway, Endpoint Monitor, Network Sensor และ System Audit
- ตรวจสอบลำดับเหตุการณ์และความเชื่อมโยงระหว่างหลักฐาน
- ตอบคำถามที่เน้นการใช้เหตุผลและการประเมินความน่าเชื่อถือของข้อมูล
- ตรวจสอบคำอธิบายหลังตอบ เพื่อเรียนรู้ว่าทำไมตัวเลือกหนึ่งจึงเหมาะสมกว่าตัวเลือกอื่น
- บันทึกความคืบหน้าของผู้เล่นในเครื่อง

## First Case

**CASE-001: THE GHOST PROCESS**

ผู้เล่นต้องตรวจสอบเหตุการณ์ผิดปกติบนเครื่องคอมพิวเตอร์ขององค์กรสมมติ NOVACORE TECHNOLOGIES โดยพิจารณาหลักฐานจากหลายระบบและแยกข้อเท็จจริงออกจากข้อสันนิษฐาน

## Requirements

ข้อกำหนดด้านซอฟต์แวร์และระบบปฏิบัติการจะระบุให้ชัดเจนในแต่ละรุ่น หลังจากทดสอบไฟล์เกมบนเครื่องที่สะอาดแล้ว

## How to Play

1. เปิดคดีและอ่านคำอธิบายสถานการณ์
2. ตรวจสอบหลักฐานจากแหล่งต่าง ๆ
3. เปรียบเทียบเวลา อุปกรณ์ กระบวนการ และข้อมูลที่เกี่ยวข้อง
4. เลือกคำตอบที่มีหลักฐานสนับสนุนดีที่สุด
5. อ่านคำอธิบายและหลักฐานอ้างอิงหลังตอบ

## Important Notes

Cyber Detective เป็นเกมจำลองเพื่อการศึกษา ใช้คดีและข้อมูลที่แต่งขึ้น ไม่ใช่เครื่องมือสแกน ตรวจสอบ หรือควบคุมระบบจริง ผลลัพธ์ในเกมไม่ใช่คำแนะนำสำหรับการสืบสวนเหตุการณ์จริง
